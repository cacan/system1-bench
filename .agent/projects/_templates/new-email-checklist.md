# New Email Checklist

Use this checklist whenever a new email is added to a thread.

- [ ] Append the new message to `thread_history.md`.
- [ ] Update the thread `README.md` with latest status and next action.
- [ ] Update any impacted project rollup docs.
- [ ] Re-ingest `.agent/projects` through the global Qdrant ingest script if the update is meaningful.
- [ ] Capture owner and ETA in the thread summary when follow-up is needed.
