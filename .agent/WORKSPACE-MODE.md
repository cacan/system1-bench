# Workspace mode

This repository uses the `gtm-initialize` scaffold for shared workspace conventions: `.agent` source-of-truth files, project/thread templates, SOP discovery, identity validation, Chrome readiness, and Qdrant naming.

It is still a non-GTM Jev-alternative evaluation workspace.

## Disabled by policy

- GTM and GA4 services are disabled.
- No GTM account, container, workspace, export, tag, trigger, variable, or live-check data belongs here.
- No Search Console, Ads, Merchant, BigQuery, Dataform, or Cloud Storage project work is enabled.
- Google Workspace APIs and Gmail remain disabled for this project.
- Hindsight remains deferred until a dedicated project bank is explicitly provisioned.

## Dormant initializer files

Files whose names contain `GTM`, `GA4`, or GTM audit terminology were generated by the standard initializer as dormant templates and navigation references. They are not evidence that those services are enabled. Do not populate or use them for live operations unless the workspace scope is explicitly changed.

The active project source of truth remains:

- `config/workspace.toml`
- `config/providers.toml`
- `.agent/google-workspace-identity.json`
- `.agent/qdrant.toml`
- `alternatives/manifest.toml`
- `benchmarks/`
- `docs/`
